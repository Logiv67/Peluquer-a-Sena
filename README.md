# Peluqueria-Sena
Peluquería con node, MySQL, JavaScript
05-09-2026 se creó los requisitos funcionales

1 que el Software muestre a clientes los trabajadores disponibles 

A debe existir un admin que pueda crear a ese usuario cliente. 
B cliente puede crear su propia cuenta. 
C que ese usuario pueda validarse en el sistema si es real o no para poder ver la lista de trabajadores. Con esta información tendríamos esto. 
D debe existir una vista para que el admin cree esos trabajadores. Si no el cliente o usuario no podrá verlos. 
E debe existir una vista que valide los trabajadores y miro los pedidos que me llegaron o los turnos que me tocan, para eso debe demostrarse que es un trabajador, cómo?  con un login, (validación de usuario). Aqui el trabajador no puede crear su propia cuenta 

2 que el usuario o cliente pueda visualizar horarios de trabajadores disponibles. 

A el cliente pueda visualizar horarios de trabajadores disponibles. 
B que el admin pueda visualizar horarios de trabajadores disponibles. 
C que el trabajador pueda visualziar sus horarios de trabajadores disponibles. 
D que el trabajador pueda editar los horarios de trabajadores. 
E que el trabajador elimine horarios de trabajadores  
F admin pueda eliminar horarios de trabajadores

RF02 EL Sistema debe permitir al nuevo cliente crear su nueva cuenta.

RF04- El sistema debe permitir al admin crear una cuenta nueva de trabajadores. 
RF05- El sistema debe permitir al nuevo trabajador entrar al sistema. 
RF06- El sistema debe permitir al cliente visualizar horarios del trabajador. 
RF07- El sistema debe permitir al admin visualizar los horarios del trabajador 
RF08- El sistema debe permitir al trabajador visualizar sus horarios. 
RF09- El sistema debe permitir al trabajador editar su horario 
RF10- El sistema debe permitir al trabajador eliminar el horario  
RF11- El sistema debe permitir al admin editar el horario, 
RF12- El sistema debe permitir al admin eliminar el horario,
